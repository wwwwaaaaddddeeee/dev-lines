Before you ship the bug.

Center, width, and padding guides — plus depth-colored outlines and labels around every layout box. On localhost, in any framework, without touching your markup.

Features

⌗
Center cross — vertical + horizontal viewport center.
│
Content & padding edges — guides at your container width and page padding.
▢
Depth-colored outlines — every layout box, colored by nesting depth.
⊞
Auto-detect — finds flex/grid containers; opt in or out with one data attribute.
⌶
Labels — hover any box for tag · size · layout; name your own regions with data-devlines-name; px readouts on the guides.
↔
Distances — hold Alt to measure the gaps from the hovered box to its container.
⧉
For agents — every box gets a name (yours via data-devlines-name, or auto from id / aria-label / heading); press C to copy its handle + selector. Point your AI agent at a section by name.
∅
Non-invasive — drawn as an overlay; never mutates your styles. Zero dependencies.
⏻
Toggle & persist — one shortcut on/off, remembered across reloads.

Props

contentWidthpx; draws content-width edge guides at center ± half. Omit to hide.
paddingXpx; draws padding edges this far in from each side.
depthColorssection-outline palette by nesting depth (wraps).
sectionsoutline layout containers. Default true.
labels{ mode, show, guides } — mode off · hover · all; fields and guide readouts.
nameAttrattribute read for a box's name. Default data-devlines-name.
autoNamederive a name from id / aria-label / component / heading when none is set.
shortcuttoggle combo. Default mod+shift+l.
persistremember on/off across reloads.

Commands

⌘/Ctrl ⇧ LToggle dev-lines on/off
OToggle outlines
GToggle guides
LCycle labels — off → hover → all
hold AltDistances from the hovered box to its container
CCopy the hovered box's handle — name · selector · tag
